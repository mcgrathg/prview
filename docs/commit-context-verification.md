# Commit context — 2026-11-08

Enhanced diff file headers reveal a small commit icon on hover or keyboard focus (visible on touch). It opens a compact nonmodal popover, using the selected file and immutable comparison. It does no work until requested and adds no row, column or persistent panel. Escape/Close restores header focus. Commit links open GitHub explicitly; inspection does not change the review URL.

The reader reuses the local mirror/search context and Git range semantics. It reads `base..head` for the literal current path and displays real first-line titles and message bodies. This differs from the existing file history, which reads earlier history from the base branch. Results are file-level candidates rather than exact hunk attribution; renames are not followed. The latest 30 matches are shown, with truncation disclosed. No message body is synthesized.

The endpoint validates full SHAs, repository/ref format and bounded repository-relative paths. Git runs as argument arrays with literal pathspecs and external diff, textconv and lazy fetch disabled. A 5-second timeout, streamed 512KiB cap, request abort and bounded commit count limit the read. NUL-separated frames require valid commit SHAs; unsupported/missing history remains explicit. Lookup actors own cancellation on close, navigation, comparison changes and unmount. Rendering uses escaped Svelte text. The spawn options were checked against the [Bun API reference](https://bun.sh/reference/bun/spawn).
