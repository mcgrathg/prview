# Repository neighborhoods

Patterns is a separate investigation browser mode from semantic usages. It combines parsed static import/re-export facts with pinned Git catalog candidates and bounded literal mention search. Each entry names its reason. Relative module targets resolve against tracked paths, preserving ambiguity; packages and aliases remain explicit gaps. Dynamic/CommonJS dependency discovery is not implemented. Filename similarity, directory proximity, test naming and guidance/ADR paths are discovery hints; the app makes no canonical-pattern or test-coverage verdict.

The existing question research actor owns the lifecycle: BROWSER.SET captures a new neighborhood origin and cancels the prior request; typing replaces the query, Explore captures a candidate origin, and close/teardown aborts transport. Results preserve the exact revision. Explore changes browser context, while Inspect, Open and Beside retain their distinct code transitions. Filename/guidance categories cap40, literal mentions60, parsed imports200, visible filtered results200; all incompleteness is disclosed.

Save evidence captures the original request and question identity before loading source. It creates a new private finding only after pinned excerpts load. Dependencies save both target source and importing statement; other candidates save their target snippet and reason. PR teardown aborts these reads, and notebook capacity cannot cause an existing finding to be overwritten. Finding text stays outside the URL and preparing a draft remains a separate explicit action.
